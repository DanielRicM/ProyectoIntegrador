## DESCRIPCIÓN

Este proyecto desarrollado en Java integra distintos tipos de acceso a datos en una interfaz por linea de comandos. Ha sido desarrollado implementando diversas interfaces y mecanismos genéricos, lo que facilita la adición de nuevas entidades, aumentando la escalabilidad.

--- 

## INSTRUCCIONES

- Copiar "/ProyectoIntegradorDIServer" al directorio htdocs de xampp o su servidor http preferido.
- Inicializar base de datos mongoDB
- Para configurar cualquier ruta de acceso o credencial propios del entorno en el que se ejecute el programa, se pueden editar los parametros en src/resources/config.properties
